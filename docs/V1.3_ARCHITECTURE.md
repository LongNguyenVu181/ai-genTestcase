# V1.3 architecture

## AI responsibility

AI only analyzes source requirements into the existing Rule Matrix JSON schema.

No AI is used to:
- render XMind;
- create Excel;
- transform the Rule Matrix into display cards;
- persist testcase edits.

## Hidden internal JSON

Rule Matrix remains stored in SQLite in `analysis_runs.matrix_json`.

Normal UI endpoints do not return this matrix. A debug download endpoint remains:
`GET /api/runs/{run_id}/rule-matrix`

## Deterministic mapping

`backend/testcase_mapper.py` maps:
- `rule_id` -> ID
- `rule_name` -> Name
- `test_condition` -> PreConditions / Data test according to deterministic rules
- `test_objective + target + test_condition` -> Step
- `expected_result` -> Expected Result
- `category` -> Type
- `feature_group + feature_name` -> review grouping

## Persistence

SQLite schema is in `backend/db.py`.

## Excel

`backend/excel_export.py` writes the Senior-QA workbook directly from DB testcase objects.
